# XAUUSD Autonomous Trading System

Expert Advisor modular para MetaTrader 5 (Deriv), especializado en XAUUSD, intradía (H1/M15/M5), sesiones de Londres y Nueva York.

> **Estado: Fase 1 (diseño).** No hay código ejecutable. No se promete rentabilidad: el objetivo es un sistema técnicamente sólido, medible y validado en backtest y demo. El trading real está deshabilitado por diseño.
