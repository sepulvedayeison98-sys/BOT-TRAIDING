# XAUUSD Autonomous Trading System

Expert Advisor modular para MetaTrader 5 (Deriv), especializado en XAUUSD, intradía (H1/M15/M5), sesiones de Londres y Nueva York.

> **Estado: Fase 7 (ejecución y posiciones) completada.** Todavía no hay EA que opere: solo módulos de análisis, herramientas de diagnóstico/validación y pruebas. No se promete rentabilidad: el objetivo es un sistema técnicamente sólido, medible y validado en backtest y demo. El trading real está deshabilitado por diseño.
